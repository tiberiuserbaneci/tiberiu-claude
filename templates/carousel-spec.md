# Carousel Spec — Dark Cyber-Noir System

## Brand Rules

1. Domain: 51ultron.com — NEVER ultron.com alone
2. NEVER put pricing on the last slide
3. Last slide is ALWAYS a Comment CTA
4. Brand header on cover: ULTRON + 51ultron.com
5. No other company names on any slide — only ULTRON

## Visual System

| Element | Value |
|---------|-------|
| Background | #0a0a0f (deep black with blue undertone) |
| Panel BG | #111118 |
| Accent | #ff6b00 (orange) |
| Accent Dim | #cc5500 |
| Text Primary | #e8e8ec |
| Text Dim | #888899 |
| Border | #22222c |
| Font | JetBrains Mono (monospace / terminal feel) |

## Slide Types

### Cover Slide
- Full-width, centered
- Large headline (64px)
- Subtitle below
- Section flare above headline: "TOPIC.ANGLE"

### Data Slide
- Section flare top-left
- Badges inline (PRO, NEW, BETA)
- Headline + subheadline
- Max 720px text width

### 3-Column Slide
- Section flare
- Headline
- 3 columns with number, title, body
- Column background: rgba(255,255,255,0.03)

### CTA Slide
- Engagement prompt in large type
- "Comment [WORD] if you want [THING]"
- Footer: ULTRON // AI GTM OPERATING SYSTEM | 51ultron.com

## Content Patterns

### Slide Sequence (6 slides):
1. Hook — contrarian claim
2. Context — numbers + credibility
3. Problem — what most do wrong
4. Mechanism — how it works (protocol, chain)
5. Use cases — 3 verticals with columns
6. CTA — comment engagement

### Typography Scale
- H1 (cover): 64px
- H2 (slide titles): 36px
- H3 (column titles): 22px
- Body: 16px
- Caption/Column body: 13px
- Flare/Badge: 10-11px

## Export

Chrome print-to-PDF at 1080x1350 per slide (LinkedIn optimal).
Or use `html2canvas`/`puppeteer` for automated PNG export.
