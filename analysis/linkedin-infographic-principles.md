# LinkedIn Infographic Principles

> Reference framework: "How to create a high-performing LinkedIn infographic" (Marina Panova).
> Added to the learning set 2026-06-02. Reinforces and extends CLAUDE.md §13 (scoring),
> §16 (layouts), and §26 (validated virality principles, especially the SAVES lever).

## The 8 principles

1. **Pick ONE core idea.**
   - Bad: too many ideas, random advice, no clear takeaway.
   - Good: one problem, one framework, one transformation.
   - Ask: "What should people remember 5 minutes later?"

2. **Make the title instantly clear.** The headline should stop the scroll, create curiosity fast, and explain the outcome.
   - Bad: "Thoughts on content"
   - Better: "How To Build A LinkedIn Content System"
   - Best: "The LinkedIn Algorithm Cheatsheet"
   (Name the asset. A "cheatsheet / map / system" title signals a save-worthy reference.)

3. **Structure matters more than design.** Best-performing layouts are highly scannable, section-based, visually balanced, and easy to skim in 10 seconds. Use numbered sections, spacing, boxes, contrast, and visual hierarchy.

4. **Optimize for SAVES.** Most viral infographics are NOT motivational. Ask: "Would someone save this to use again?" They are practical, referenceable, actionable, and easy to revisit later.

5. **Do not overload the graphic.** Too much text kills retention. Simplify complex ideas, remove unnecessary words, make insights easy to consume. Clarity always wins.

6. **Focus on scannability.** Most people will not fully read it, they scan first. So: short paragraphs, spacing, bold headers, visual rhythm, clean structure. It should feel effortless to read.

7. **Build recognizable branding.** The strongest creators become recognizable instantly. Keep colors, structure, typography, layouts, and tone consistent. Memorability compounds over time.

8. **End with one clear CTA.** Examples: "Save this for later", "Repost to help others", "Follow for more frameworks". One CTA, not five.

## Pre-publish checklist (6 questions)
- [ ] Is it easy to scan?
- [ ] Is the idea immediately useful?
- [ ] Is the title clear?
- [ ] Is it visually structured?
- [ ] Would people save it?
- [ ] Would someone repost it?

## Format note (from the embedded example)
The reference's own example is a "2026 LinkedIn Algorithm Cheatsheet" rendered as a dense,
numbered, section-based cheatsheet (about 12 labeled boxes). That is the canonical
**referenceable-cheatsheet** format: one named asset, numbered sections, scannable in 10 seconds,
built to be saved and revisited. It is the visual embodiment of principles 2, 3, and 4.

## How this maps to our existing config
- **Reinforces §26 SAVES lever:** "would someone save this to use again" = our reference-grade asset
  + explicit save ask. Practical / referenceable / actionable beats motivational.
- **Reinforces §13 scoring:** principle 1 (one idea) and 6 (scannability) feed the Save-Worthy and
  Visual dimensions; the 6-question checklist is a fast pre-score gate.
- **Extends §16 layouts:** the named-cheatsheet / numbered-section layout is a save-first template to
  add to the rotation.
- **Caveat vs our channel split:** our docs-02 routing poster already follows most of this (one idea,
  named "routing map", numbered rows, save framing). The one tension is branding consistency
  (principle 7): LinkedIn uses Dark Ultron, TikTok uses the reference glass format by operator choice.
