title: "Troubleshooting"
description: "Common issues and how to fix them."
---

## Chat not working

- Check that you've connected a Claude API or OpenRouter key on the Integrations page
- Verify your API key is valid and has credits
- Try refreshing the page and starting a new conversation

## Channel not connecting

- Make sure you're sending the correct workspace code: `/connect UTR-XXXXXX`
- Check that the Ultron bot is active in your channel
- Try disconnecting and reconnecting: `/disconnect` then `/connect`

## Leads not appearing in dashboard

- Lead generation requires the **Max plan** for full execution
- Free plan shows preview only (leads are not stored)
- Check the Leads page filter — you might be filtering them out

## Content not matching my voice

- Re-calibrate your voice in **Settings → Business Profile**
- Provide more voice samples (2-3 of your best posts)
- Be more specific about tone: "direct, short sentences, no jargon"

## Agent not running on schedule

- Check agent status on the Agents page (should show "active")
- Verify the schedule configuration
- Check the error log for failed tasks

## Need help?

Contact us through the dashboard or email support. We respond within 24 hours.
