## Schedule Types

| Type | Description | Example |
|---|---|---|
| **Fixed** | Runs at a specific time | Daily at 8 AM, Weekly on Monday |
| **Event** | Triggered by a database event | When a new lead comes in |
| **On-demand** | Manually triggered | Click "Run" in dashboard |
| **Continuous** | Always running | Monitoring/alerting agents |

## Morning Brief Agent

A special agent that compiles a daily summary:
- New leads found overnight
- Deals that need follow-up today
- Content scheduled for publishing
- Agent performance summaries
- Key metrics changes

Delivered to your Telegram, Slack, or WhatsApp every morning.

## Managing Schedules

```
"Change SDR agent to run twice daily"
"Pause all agents until Monday"
"Set research agent to run at 6 AM instead"
"Add weekend runs to the content agent"
```
