## Deploying an Agent

Say: **"Deploy an SDR agent that runs every morning"**

Ultron creates:
1. Agent record in the `agents` table
2. Schedule configuration (frequency, time, tasks)
3. Webhook URL for external triggers (optional)
4. N8N workflow ID for automation chains (optional)

## Agent Performance

Each agent tracks:

| Metric | Description |
|---|---|
| Tasks Completed | Successfully finished tasks |
| Tasks Assigned | Total tasks given |
| Tasks Failed | Errors or failures |
| Performance Score | Success rate (0-100) |
| Last Active | Most recent execution |
| Error Log | Failed task details |
