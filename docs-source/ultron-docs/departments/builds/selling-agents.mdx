## The Business Model

Build once, sell many times. Package any agent as a monthly subscription product for clients.

## How it works

<Steps>
  <Step title="Build the agent template">
    Create and test an agent that solves a specific problem (e.g., AI SDR, AI Content Manager).
  </Step>
  <Step title="Configure for client use">
    Set up the agent to work with the client's data, integrations, and preferences.
  </Step>
  <Step title="Set pricing">
    Define a monthly retainer (e.g., $300-$1,000/month per agent).
  </Step>
  <Step title="Deploy under client workspace">
    Each client gets their own isolated workspace with their own data.
  </Step>
  <Step title="Monitor and optimize">
    Track performance from your dashboard. Iterate based on results.
  </Step>
</Steps>
