## What is a Campaign?

A campaign groups leads under a single outreach strategy. Each campaign has:
- Target description (ICP for this campaign)
- Email template
- Follow-up sequence
- Performance metrics

## Campaign Metrics

| Metric | Description |
|---|---|
| Leads Count | Total leads in campaign |
| Emails Sent | Outreach messages delivered |
| Opens | Emails opened |
| Replies | Responses received |
| Meetings Booked | Calls/demos scheduled |
| Opt Outs | Unsubscribe requests |

## Campaign Statuses

`Draft → Active → Paused → Completed`
