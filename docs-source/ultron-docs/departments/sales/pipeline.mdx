## Pipeline Stages

```
Discovery → Proposal → Negotiation → Verbal → Contract → Won / Lost
```

| Stage | Probability | Typical Duration |
|---|---|---|
| Discovery | 10% | 1-2 weeks |
| Proposal | 30% | 1 week |
| Negotiation | 50% | 1-2 weeks |
| Verbal | 70% | 3-5 days |
| Contract | 90% | 3-5 days |

## Pipeline Commands

```
"Pipeline status" — Full overview with counts per stage
"Pipeline value" — Total weighted pipeline value
"Deals closing this month" — Upcoming closes
"Move [deal] to [stage]" — Update deal stage
"New deal: [company], $[value]" — Create new deal
```
