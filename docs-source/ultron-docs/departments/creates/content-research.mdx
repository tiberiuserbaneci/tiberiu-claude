## Research Reports

When you ask Ultron to research content trends, it generates a report stored in the `content_research` table:

| Field | Description |
|---|---|
| Topic | What was researched |
| Platform | Which platform(s) |
| Trending Hooks | Top-performing hook patterns |
| Competitor Analysis | What competitors are posting |
| Recommendations | Actionable content suggestions |

## Connected Integrations

| Integration | What it adds |
|---|---|
| **Apify** | Deep scraping of LinkedIn, Twitter, Instagram profiles and posts |
| **Web Search** | Real-time trend discovery (built-in, no key needed) |

## Example Prompts

```
"Research what's working in AI automation content on LinkedIn"
"Analyze my top 3 competitors' content strategy"
"What hooks are converting best on Twitter this week?"
"Give me a content gap analysis for my niche"
```
