## Repurposing Flow

```
Original Post (LinkedIn)
    → Twitter Thread (reformatted for 280 chars)
    → Instagram Carousel (visual slide deck)
    → Substack Article (expanded long-form)
    → Email Newsletter (personal digest)
```

## How to use it

Say: **"Repurpose [content] for [platforms]"**

Ultron takes any piece of content and reformats it for each target platform, adjusting:
- Length and structure
- Formatting conventions
- Hook style
- CTA placement
- Hashtag usage

## Example

```
"Repurpose my last LinkedIn post for Twitter, Instagram, and email"
"Take this article and create 5 LinkedIn posts from it"
"Turn this thread into an Instagram carousel"
```
