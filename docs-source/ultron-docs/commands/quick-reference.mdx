## Universal Commands

| Command | What it does |
|---|---|
| `"Help"` | Show available commands for current department |
| `"Switch to [department]"` | Change department (sales, creates, builds) |
| `"Update my ICP"` | Re-run ICP configuration |
| `"Update my voice"` | Re-calibrate content voice |
| `"What's my plan?"` | Show current plan and usage |
| `"Status"` | Overview of all departments |
