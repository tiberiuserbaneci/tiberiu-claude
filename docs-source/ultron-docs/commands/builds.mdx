## Deployment

| Command | Example |
|---|---|
| `"Deploy [type] agent"` | "Deploy an SDR agent" |
| `"Create agent that [task]"` | "Create an agent that monitors competitor pricing" |
| `"Deploy [agent] running [schedule]"` | "Deploy SDR agent running every morning at 8 AM" |
| `"Show agents"` | List all deployed agents |
| `"Agent status"` | Show all agents with metrics |

## Management

| Command | Example |
|---|---|
| `"Pause [agent]"` | "Pause the content agent" |
| `"Resume [agent]"` | "Resume the SDR agent" |
| `"Retire [agent]"` | Permanently deactivate |
| `"What did [agent] do today?"` | Show recent task log |
| `"Agent performance"` | Performance scores for all agents |

## Configuration

| Command | Example |
|---|---|
| `"Change [agent] schedule"` | "Change SDR agent to twice daily" |
| `"Add task to [agent]"` | "Add competitor monitoring to research agent" |
| `"Connect [agent] to N8N"` | Link to automation workflow |
