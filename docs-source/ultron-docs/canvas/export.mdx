Every canvas renders with an export button. No extra steps, no separate tool required.

## Export formats

| Format | Best for |
|--------|----------|
| **PDF** | Board decks, client presentations, print-ready documents |
| **PNG** | Slack sharing, email attachments, slide decks |

## How to export

1. A canvas renders inline in your chat thread
2. Click the export icon in the top-right corner of the canvas
3. Select PDF or PNG
4. File downloads to your browser immediately

File names are generated automatically based on canvas type and subject: `hubspot-vs-salesforce-comparison.pdf`, `acme-corp-swot-grid.png`.

## What exports correctly

- All text content
- Charts and data visualizations
- Tables and grids
- Color styling and layout
- Multi-section canvases (Sales Blueprint, Post-Call Blueprint, Structured Doc)

## Batch export

Multiple canvases generated in the same session each have independent export buttons. There's no single-click batch export — each canvas is exported individually.

<Tip>
  For client-facing documents, PDF export from the Sales Blueprint or Structured Doc canvas produces a clean, professional output that doesn't look AI-generated.
</Tip>
