## How Usage is Tracked

Every user has a `usage_tracking` record per day that counts:
- Conversations started
- Messages sent
- Leads generated
- Content created
- API calls made

Free tier checks are enforced before every AI call. When you hit the limit, Ultron tells you and suggests upgrading.
