---
title: "Apollo.io"
description: "Verified contact data and company firmographics for Specter's lead lists."
---

Apollo gives Specter access to a database of 275M+ contacts with verified email addresses, phone numbers, and company data. Without Apollo, Specter can still find leads via web search — but with Apollo, the data is richer and emails are verified.

## What it enables

- Verified email addresses for every lead (not guessed, not scraped)
- Phone numbers for contacts
- Company firmographics: headcount, funding stage, revenue range, tech stack
- Advanced filtering: industry, location, employee count, job title, funding history
- Intent data: companies actively researching solutions like yours

## How to connect

<Steps>
  <Step title="Get your Apollo API key">
    1. Log in to [app.apollo.io](https://app.apollo.io)
    2. Go to **Settings → Integrations → API**
    3. Click **Create API Key**
    4. Copy the key
  </Step>
  <Step title="Add it to Ultron">
    1. Open your Ultron dashboard → **Integrations**
    2. Find the Apollo card and click **Connect**
    3. Paste your API key and save
  </Step>
  <Step title="Test the connection">
    Ask Specter for a lead: _"Find 3 CTOs at logistics companies in Texas."_ If Apollo is connected, you'll see enriched data with verified emails in your Leads table within a few minutes.
  </Step>
</Steps>

## Without Apollo

Specter still works without Apollo — it uses web search and public data to find companies and contacts. But emails won't be verified and firmographic data will be less complete. Apollo significantly improves lead data quality.

## API key security

Your Apollo API key is encrypted before being stored. It's never visible in your browser or accessible by other users. Specter uses it server-side when executing lead generation tasks.
