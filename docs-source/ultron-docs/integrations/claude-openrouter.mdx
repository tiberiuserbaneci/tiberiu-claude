-e ## Setup

**Option A: Anthropic (Recommended)**
1. Go to [console.anthropic.com](https://console.anthropic.com)
2. Create an API key
3. Paste into the Claude API card on Integrations page

**Option B: OpenRouter**
1. Go to [openrouter.ai](https://openrouter.ai)
2. Create an API key
3. Paste into the OpenRouter card

<Warning>This is the only required integration. Without it, chat does not work.</Warning>

## What it powers
Every conversation with Ultron. All department skills. Every AI execution.
