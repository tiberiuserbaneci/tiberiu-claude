-e ## What it unlocks
- Accept payments for agent subscriptions
- Manage client billing
- Track revenue from sold agents

## Setup
1. Go to [dashboard.stripe.com](https://dashboard.stripe.com) → Developers → API Keys
2. Copy your secret key
3. Paste into the Stripe card
