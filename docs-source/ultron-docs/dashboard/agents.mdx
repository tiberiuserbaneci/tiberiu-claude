## Agent Registry

Grid of agent cards showing:
- Agent name and type
- Status indicator: green (active), yellow (paused), gray (retired)
- Tasks completed
- Last active timestamp
- Performance score

## Features

- Click any agent for details, schedule, and performance history
- "Deploy New Agent" button opens chat with Clone Army
- Pause, resume, or retire agents
- View task logs and error history
- Performance analytics
