## Pipeline Stages

| Stage | Probability | Description |
|---|---|---|
| Discovery | 10% | Initial conversation, qualifying need |
| Proposal | 30% | Sent pricing or proposal |
| Negotiation | 50% | Discussing terms, scope, timeline |
| Verbal | 70% | Verbal agreement, pending paperwork |
| Contract | 90% | Contract sent, awaiting signature |
| Won | 100% | Deal closed |
| Lost | 0% | Deal lost |

## Features

- Drag and drop cards between stages
- Each card shows: company, value, contact, days in stage
- Pipeline value summary at top
- Click any deal for full details
- Proposal and contract URL tracking

**Empty state:** "No deals yet. Tell Ultron about your prospects."
