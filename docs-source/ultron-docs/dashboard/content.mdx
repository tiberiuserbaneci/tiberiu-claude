## Views

**Calendar View:** Month view showing scheduled and published content by date.

**List View:** All content pieces with status, platform, and engagement prediction.

## Content Statuses

| Status | Meaning |
|---|---|
| Draft | Created, not yet reviewed |
| Approved | Reviewed and ready to publish |
| Scheduled | Set to publish at a future date/time |
| Published | Live on the platform |

## Features

- Click any piece to preview with platform-specific formatting
- Edit drafts inline
- Reschedule with drag and drop
- Filter by platform (LinkedIn, Twitter, Instagram, etc.)
- Filter by content type (post, thread, carousel, article)

**Empty state:** "No content yet. Ask Ultron to write something."
