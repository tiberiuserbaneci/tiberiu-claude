## Home screen

The main dashboard shows four KPI counters at a glance:

- **Total Leads** — how many prospects Specter has found and saved
- **Active Deals + Pipeline Value** — open deals and total value Striker is tracking
- **Content Created** — pieces Pulse has drafted across all platforms
- **Tasks Completed** — total agent tasks completed across all agents

Below the KPIs: a live activity feed showing the last 10 agent actions. Refresh to see updates as agents work.

**Quick action buttons** (top of screen):
- **Find Leads** → opens Chat with Specter context loaded
- **Write Content** → opens Chat with Pulse context loaded
- **Research** → opens Chat with Cortex context loaded

## Navigation

The sidebar has direct links to each dashboard view. The active agent count and recent activity summary are always visible in the sidebar so you can see at a glance whether agents are running.
