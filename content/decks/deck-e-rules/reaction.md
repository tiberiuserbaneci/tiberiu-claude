# Reaction opener - deck-e-rules

**Kicker (small, above)**  Founder operating rules

**ON SCREEN** (what they read, keep it short)

> 7 rules I run my week on. Tell me one is wrong.

**YOU SAY** (over the same shot)

> I mean it. If one of these is wrong for your business, say which one and why.

**Then** slide 1, which does NOT repeat this line.

**Pattern** list-and-argue (764K, @imad.json)

> 14 rules for startups - comment any I missed

A countable list plus an explicit invitation to disagree. The comment ask is the content, not a bolt-on, so it reads as confidence rather than farming.

**Keyword** RULES
