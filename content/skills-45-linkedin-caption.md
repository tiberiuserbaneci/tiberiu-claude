## CAPTION

The same Claude prompt landed differently every morning.
A skill landed the same, every single time.

- - -

For a year I treated Claude like a genius with amnesia. Every morning I re-typed the same outbound brief, the same ICP and the same do-not-say list into a fresh chat, then graded the output on a coin flip. The model kept getting smarter and my output kept not moving. So I stopped writing prompts and started writing skills: the GTM work I keep repeating, packaged once, with a model, a tool list and a quality bar locked in so it runs the same way every time.

- - -

Here is what a skill actually is.

→ A skill is not a paragraph of hope. It ships with eight things locked before it ever sees my work: a model tier, a tool allow-list, a token budget of 8 turns, the operating procedure, its context, a quality gate, a fixed output format and a run mode.

→ My cold-email skill researches the lead, drafts one email, then holds it against a 6-point quality gate: one specific mention, subject under 6 words, body under 150 words, exactly one CTA, reads like a human, zero banned words. Fail one check and it rewrites itself, so I never see a draft that misses the bar.

→ One library covers the whole funnel. 35+ skills across research, lead-gen, sales, content and ops. I describe the job in plain English and Ultron routes to the skill that owns it.

→ The skill drafts, the gate ships. The quality gate auto-checks the work and the human gate holds the send, so nothing reaches a buyer until I approve it.

→ It compounds. Every run saves what worked, what failed and the correction, so run 50 of my cold-email skill is sharper than run 4. The lessons load before the next run even starts.

- - -

The unlock was never a smarter model. A smarter model on its own changed almost nothing for me. The real leverage was refusing to let the AI improvise the parts that should never change. A prompt asks for brilliance on demand and prays. A skill makes brilliance the floor, then makes it repeatable, and repeatable is the only thing that compounds.

Save this carousel. It is the anatomy of a skill plus the 35+ I run my GTM on.
