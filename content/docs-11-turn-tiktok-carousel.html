Step 4 · tool catalog
Every turn gets a scoped catalog
Provider modulesfirst
Modular, sim-style tool packs are loaded ahead of everything else.
MODULES.flatMap(m => m.schemas)
Native handlers91 tools
The native catalog, filtered by the skill allow-list. No allow, no call.
getNativeTools().filter(allow-list)
External MCPcached 10 min
Per-user external servers, discovered and cached for the session.
getExternalServerTools(userId)
The allow-list is enforced. A skill cannot call a tool outside its manifest, even if the model attempts to.

The Chat Loop07 / 08
Stop conditions
4 ways a turn ends
tool_use→loops again
the only stop reason that keeps the loop running
end_turn→idle
the model returned a final assistant message
max_tokens→idle + warning
the turn budget was reached before the model finished
error→failed
an unrecoverable tool or model error
Every message, tool call and result is persisted. The database is the source of truth, streaming is UI only.
