# Nine ways to show N tools in 1080x1080

Built by `content/_layouts.py`. The content is identical in all nine (eight tools, the last one
locked, real brand marks where the repo has them) so the only variable is the form.

Every layout trades the same three things against each other. That trade is what to choose on:

| | Logo size | Words per tool | Tools before it breaks | Survives a thumbnail |
|---|---|---|---|---|
| 01 list | 62px | name + one line | 8 | no |
| 02 two columns | 60px | name + one line | 8 | no |
| 03 icon wall | **132px** | name only | 9 | **yes** |
| 04 ranking | 54px | name + one line | 10 | no |
| 05 bento | 104px hero | hero gets two lines | 8 | partly |
| 06 radial | 86px | name only | 8, exactly | partly |
| 07 receipt | 38px | job + price | 10 | no |
| 08 home screen | **148px** | name only | 9 | **yes** |
| 09 pipeline | 52px | name + job | 8 | no |

## The thumbnail point, which matters more than it looks

Hook rate is decided by the first frame at feed size, roughly 200px wide. At that size a list, a
ranking and a receipt all collapse into grey horizontal stripes: nothing is readable, so the only
thing selling the post is the hook band above it. The icon wall and the home screen still read,
because a 148px logo is still ~28px in the thumbnail and brand marks are recognisable at that size.

That is a real lever on the one metric the seven-post record showed we do not control: the wall and
the phone are the only two shapes whose BODY does any work before the viewer decides to stop.

## What each one is for

**01 list** the current default. Best words-per-tool, worst thumbnail. Use when the descriptions
are the value.

**02 two columns** same words in half the width, so it buys vertical room for a bigger hook. Feels
more like a catalogue than a recommendation.

**03 icon wall** maximum recognition, zero explanation. Use when the tools are famous enough to
carry themselves, and put the meaning entirely in the hook.

**04 ranking** the numerals imply an order and an argument, which invites "why is that one third".
The only layout that structurally provokes disagreement, so the best candidate for comments after
the locked row.

**05 bento** one tool is the point and the rest are context. This is the natural home for the
withheld row: the hero slot IS the thing you are not naming, and the seven small ones prove you are
not hiding a weak list.

**06 radial** everything orbits one centre. Only honest when that is actually true (a hub and
spokes), and it fixes you at exactly the number that divides the circle evenly.

**07 receipt** the money layout. Itemised, with a total, and it says the number without ever
claiming income, which is the veiling CLAUDE.md 33 asks for. Highest forward instinct of the nine:
a total at the bottom is the thing somebody screenshots to their partner.

**08 home screen** instantly familiar, so it reads before it is understood. Strongest thumbnail of
the nine and the most likely to be mistaken for a real screen, which is exactly why it stops a
scroll.

**09 pipeline** order is the message. Use only when the tools genuinely hand off to each other,
otherwise the arrows are decoration.
