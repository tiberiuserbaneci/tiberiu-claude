# Metoda 3: Claude

Referință păstrată separat.

Flux: brief -> biblioteca offline de logo-uri -> layout reutilizabil -> SPECS centralizat -> HTML complet -> still -> preflight -> randare 210 frames -> scrub -> caption -> livrare.

Caracteristică: imaginea nu este coaptă într-un JPEG. Headerul, body-ul, logo-urile, tipografia, CTA-ul și reveal-ul rămân HTML și sunt randate de același motor Chromium.

Scripturi de referință: `_logos.py`, `_layouts.py`, `_reveal9.py`, `_film.py`, `_preflight.py`, `_scrub.py`.
