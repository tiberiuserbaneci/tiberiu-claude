## How to add them

1. Profile > Featured > add a Link, paste the URL.
2. LinkedIn pulls the page title and description. Overwrite both with the text above.
3. Replace the auto-pulled thumbnail with the matching PNG.
4. Order them 01, 02, 03. The mast carries `01 / 03`, `02 / 03`, `03 / 03` so the row reads in sequence.
5. Paste the ALT text into the image alt field.

## Design notes

- One system, three accents: book, kraft, book-dark. At carousel size the three thumbnails
  stay distinct instead of reading as one duplicated card.
- Density is tuned for the thumbnail. Featured renders at roughly 320 x 167 px, so each card
  leads with one dominant read (headline, or the 1,686 counter) and keeps the packed detail
  for the full-size click. This is the one place where the maximum-density rule works against
  the format.
- Shared chrome across all three: mast keywords left, ordinal right, Ultron footer with the
  exact URL path. That is what makes the row read as a set.
